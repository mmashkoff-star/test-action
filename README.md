# Time API

Простой тестовый бэкенд на FastAPI. Возвращает текущее время и дату сервера, а также конвертирует время между часовыми поясами.

## Требования

- Python 3.10+

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
uvicorn main:app --reload
```

Сервер будет доступен по адресу: http://127.0.0.1:8000

## Эндпоинты

| Метод | Путь       | Описание                                      |
|-------|------------|-----------------------------------------------|
| GET   | `/`        | Проверка работоспособности                    |
| GET   | `/time`    | Текущее время сервера (UTC)                   |
| GET   | `/date`    | Текущая дата сервера (UTC)                    |
| GET   | `/convert` | Конвертация времени между часовыми поясами    |

### Пример ответа `/time`

```json
{
  "utc": "2026-08-06T14:05:00.123456+00:00",
  "unix": 1786015500.123456,
  "timezone": "UTC"
}
```

### Пример ответа `/date`

```json
{
  "date": "2026-08-06",
  "year": 2026,
  "month": 8,
  "day": 6,
  "weekday": "Thursday",
  "timezone": "UTC"
}
```

### `GET /convert`

Параметры:

| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| `to`     | да           | Целевой пояс (IANA), например `Asia/Bangkok` |
| `from`   | нет          | Исходный пояс, по умолчанию `UTC` |
| `time`   | нет          | Время в ISO 8601; если не указано — текущее UTC |

Пример:

```bash
curl "http://127.0.0.1:8000/convert?time=2026-08-06T12:00:00&from=UTC&to=Europe/Moscow"
```

```json
{
  "input": "2026-08-06T12:00:00",
  "from": "UTC",
  "to": "Europe/Moscow",
  "source": "2026-08-06T12:00:00+00:00",
  "converted": "2026-08-06T15:00:00+03:00",
  "unix": 1786017600.0
}
```
