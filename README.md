# Time API

Простой тестовый бэкенд на FastAPI. Возвращает текущее время сервера.

## Требования

- Python 3.10+

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
uvicorn main:app --reload
```

Сервер будет доступен по адресу: http://127.0.0.1:8000

## Эндпоинты

| Метод | Путь   | Описание                          |
|-------|--------|-----------------------------------|
| GET   | `/`    | Проверка работоспособности        |
| GET   | `/time`| Текущее время сервера (UTC)       |

### Пример ответа `/time`

```json
{
  "utc": "2026-08-06T14:05:00.123456+00:00",
  "unix": 1786015500.123456,
  "timezone": "UTC"
}
```
